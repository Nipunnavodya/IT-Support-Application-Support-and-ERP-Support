## 📌 Domain Overview
This repository contains enterprise IT service desk workflows, open-source ERP system configurations, and production application diagnostics aligned with ITIL service delivery standards.

---

## 🚀 Projects & Deliverables

### 1. ITSM Service Desk Setup (Jira Service Management)
* **Tool:** Jira Service Management
* **Project Scope:** Deployed an IT customer support portal for internal and external incident resolution.
* **Key Implementation:**
  * Built customer-facing request catalogs for Hardware, Software, and System Access requests.
  * Configured dynamic SLA rules with threshold warnings for First Response and Resolution targets.
  * Established automated triage workflows, escalation paths, and technician assignments.

### 2. ERP Open-Source Implementation (Odoo)
* **Tool:** Odoo (Community / Open Source)
* **Project Scope:** Deployed and configured core operational business modules for a retail enterprise.
* **Key Implementation:**
  * Set up multi-location Inventory tracking with minimum-stock rules and automated reordering.
  * Streamlined Sales Order pipelines from quotation confirmation through to fulfillment.
  * Integrated customer billing and automated vendor invoice matching.

### 3. Log Monitoring & Bug Debugging (Postman + ELK)
* **Tool:** Postman / Application Log Analyzers
* **Project Scope:** Triaged server error telemetry to troubleshoot and resolve production API failures.
* **Key Implementation:**
  * Filtered application logs to isolate recurring HTTP 400 (Bad Request), 404, and 500 (Internal Server) errors.
  * Traced database timeout exceptions and unhandled null payload fields.
  * Documented Root Cause Analysis (RCA) reports with precise remediation recommendations.
